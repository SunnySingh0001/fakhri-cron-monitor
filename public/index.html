API Documentation & AWS Elastic IP Verification Guide

1. AWS Elastic IP Kaise Verify Karein?

Jab aap AWS EC2 par koi application ya cron job chalate hain aur chahte hain ki wo is API ko call kare, toh:

  1. Apne AWS Console me jakar apne EC2 instance par Elastic IP allocate aur associate karein (e.g. 13.235.40.10).
  2. Is dashboard ke "Allowed IPs" card me apna wahi AWS Elastic IP add karein.
  3. Apne AWS EC2 instance ke terminal me SSH karke ye command run karein:
curl -X GET "http://<YOUR_SERVER_IP>:4000/api/records"

Expected Output: Agar EC2 instance ki Elastic IP match hoti hai toh HTTP 200 OK aayega. Agar Elastic IP associate nahi hui ya doosre IP se call gaya toh HTTP 403 Forbidden aayega.

2. Protected CRUD Endpoints Reference

GET /api/records Fetch All Records

Returns list of all records. Blocked with 403 if IP is not whitelisted.

POST /api/records Create New Record

Payload: { "name": "Task 1", "category": "API", "environment": "AWS" }

PUT /api/records/:id Update Record

Updates existing record by ID.

DELETE /api/records/:id Delete Record

Deletes record by ID.

3. Terminal cURL Simulation Command

Testing ke liye custom header x-simulated-ip bhej kar kisi bhi IP se simulation test kiya ja sakta hai:

# Test with authorized IP (Returns 200 OK)
curl -H "x-simulated-ip: 127.0.0.1" http://localhost:4000/api/records

# Test with unauthorized IP (Returns 403 Forbidden)
curl -H "x-simulated-ip: 198.51.100.99" http://localhost:4000/api/records
